# MCP по сессиям OpenCode

- Если установлен Session MCP, включать серверы может только пользователь через `/mcp-session`. Не включай их через конфиг, встроенный `/mcp`, CLI или прямой API вместо пользователя.
- Используй только MCP, доступные в текущей сессии. Если нужного сервера нет в каталоге инструментов, назови его и попроси пользователя включить через `/mcp-session`. Не обходи ограничение другим каналом доступа.
- Сабагент по умолчанию не получает MCP. Если его задаче нужен сервер, до запуска вызови `mcp_subagents` с минимальным набором из включённых в твоей сессии.
- Выбор действует для следующих новых сабагентов до следующего вызова. Для разных наборов выполняй «выбор → запуск» последовательно, не одним параллельным батчем. `servers: []` означает запуск следующих сабагентов без MCP.
- Выбор MCP не разрешает внешние действия: отправку сообщений, изменение документов, публикацию, запуск сборок или деплой выполняй только в пределах запроса пользователя.
- Не передавай сабагентам credentials, токены и конфигурацию с секретами. Доступ к MCP выдаётся инструментом, а не копированием ключей в промпт.
