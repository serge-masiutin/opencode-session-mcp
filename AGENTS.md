# Работа с плагином

- Целевая версия — OpenCode 2.2.0. Используй документацию V2 и установленный SDK.
- `runtime.mjs` управляет подключениями и правами; `rules.mjs` задаёт правила; `gui/` содержит окно `/mcp-session`.
- Сохраняй запрет MCP по умолчанию и изоляцию сессий. Не превращай плагин в средство автоматического разрешения MCP без пользователя.
- Проверки: `npm test`, `npm run check`, `npm run build`. GUI-прокрутку проверяй нативным wheel-событием, не только присваиванием `scrollTop`.
- Не добавляй credentials, конфигурацию пользователя, журналы и тексты сессий в Git.

## GitHub

- Используй только `bin/gh`: он проверяет аккаунт `serge-masiutin` и репозиторий `serge-masiutin/opencode-session-mcp`.
- Git identity, SSH и credentials настраиваются только для этого репозитория; глобальные настройки не меняй.
- Credentials хранятся в `gh/hosts.yml` общего Git-каталога (каталог `700`, файл `600`), не в рабочем дереве.
